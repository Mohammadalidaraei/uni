# 🎓 UNI | پلتفرم دانشجویی

**UNI** یک پلتفرم دانشجویی مدرن، سبک و دوزبانه (فارسی و انگلیسی) است که اخبار دانشگاهی، اطلاعیه‌های مهم، تخفیف‌های ویژه دانشجویان و امکانات تعامل کاربران را در یک محیط یکپارچه ارائه می‌کند. هدف UNI این است که دانشجویان بتوانند سریع‌تر به اطلاعات و خدمات مرتبط با زندگی دانشگاهی دسترسی داشته باشند و مدیران نیز محتوای سامانه را به‌سادگی مدیریت کنند.

> این مخزن برای معرفی و مستندسازی پروژه منتشر شده است و شامل سورس‌کد برنامه نیست.

## ✨ UNI چه کاری انجام می‌دهد؟

- **اخبار و اطلاعیه‌های دانشگاهی:** نمایش اخبار و اطلاع‌رسانی موضوعات مهم دانشگاه، از جمله اطلاعیه‌های تعطیلی.
- **آفینو؛ تخفیف‌های دانشجویی:** معرفی پیشنهادها و تخفیف‌های ویژه دانشجویان و مدیریت زمان اعتبار آن‌ها.
- **تعامل دانشجویان:** امکان پسندیدن محتوا و ثبت دیدگاه، همراه با سازوکار مدیریت دیدگاه‌ها.
- **تبلیغات بومی:** نمایش تبلیغات هماهنگ با محیط سامانه و ثبت آمار نمایش و کلیک.
- **تجربه دوزبانه:** پشتیبانی از فارسی با چیدمان راست‌به‌چپ (RTL) و انگلیسی با چیدمان چپ‌به‌راست (LTR).
- **پنل مدیریت:** مدیریت بخش‌های مختلف سامانه، محتوا و تنظیمات.

| بخش | کاربرد |

| 🏠 خانه | مشاهده اخبار، اطلاعیه‌ها و محتوای دانشگاهی |
| 🎁 آفینو | مشاهده پیشنهادها و تخفیف‌های دانشجویی |
| ⚙️ تنظیمات | دسترسی به تنظیمات مرتبط با کاربر |
| 🛡️ پنل مدیریت | مدیریت اطلاعات و محتوای سامانه برای کاربران مجاز |

### مسیریابی و تجربه کاربری

UNI از مسیریابی مدرن مبتنی بر **HTML5 History API** استفاده می‌کند تا جابه‌جایی میان بخش‌های سامانه با آدرس‌های تمیز و بدون نشانه‌های اضافی انجام شود. همچنین باز کردن مستقیم یا تازه‌سازی صفحات پشتیبانی می‌شود.

## 👥 نقش‌ها و سطح دسترسی

| نقش | دسترسی‌ها |
| --- | --- |
| **دانشجو (User)** | استفاده از خانه، مشاهده آفینو، دسترسی به تنظیمات و قابلیت‌های تعاملی مجاز |
| **مدیر ارشد (Super Admin)** | دسترسی به خانه، آفینو، تنظیمات و پنل مدیریت برای اداره و نظارت بر سامانه |

سطوح دسترسی با توجه به نقش کاربر کنترل می‌شوند تا امکانات مدیریتی فقط در اختیار کاربران مجاز قرار بگیرند.

## 🛠️ فناوری‌ها و معماری

- **PHP 8.4 / 8.5:** پیاده‌سازی منطق سمت سرور با تایپ‌دهی صریح و قابلیت‌های مدرن PHP.
- **MySQL و PDO:** مدیریت داده‌ها و ارتباط امن با پایگاه داده.
- **Vanilla JavaScript، HTML و CSS:** ساخت رابط کاربری سبک و پویا بدون وابستگی به فریم‌ورک‌های سنگین.
- **API مبتنی بر JSON:** ارتباط میان رابط کاربری و بخش سرور.
- **معماری ماژولار:** جداسازی مسئولیت‌های احراز هویت، اعتبارسنجی، مدل‌های داده و سرویس‌ها.

### ⚡ قابلیت‌های پیکربندی Apache

پیکربندی وب‌سرور برای بهبود عملکرد، مسیریابی و امنیت سامانه در نظر گرفته شده است:

- **Clean URLs:** ارائه آدرس‌های خوانا و استاندارد و پشتیبانی از بازکردن مستقیم صفحات.
- **مسیریابی API بدون نیاز به نمایش پسوند فایل:** پردازش درخواست‌ها با URLهای ساده‌تر.
- **Gzip / Deflate:** فشرده‌سازی پاسخ‌های متنی و فایل‌های قابل فشرده‌سازی برای کاهش حجم انتقال داده.
- **کش فایل‌های استاتیک:** بهینه‌سازی بارگذاری فایل‌های CSS، JavaScript و محتوای چندرسانه‌ای.
- **محدودسازی دسترسی به منابع حساس:** جلوگیری از دسترسی مستقیم عمومی به فایل‌ها و بخش‌های داخلی برنامه.
- **هدرهای امنیتی HTTP:** استفاده از تنظیمات امنیتی مرورگر برای کاهش برخی مخاطرات رایج.

## 🔐 امنیت و مدیریت سامانه

در طراحی UNI قابلیت‌هایی مانند **کنترل نشست و سطح دسترسی، محافظت CSRF، اعتبارسنجی ورودی‌ها، محدودسازی نرخ درخواست‌ها** و **ثبت گزارش اقدامات مدیریتی** پیش‌بینی شده است. همچنین سازوکار تأیید هویت با کد یک‌بارمصرف (OTP) و سرویس پیامک در معماری پروژه وجود دارد.
