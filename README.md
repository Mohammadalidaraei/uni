# 🎓 پلتفرم دانشجویی UNI (نسخه مدرن PHP 8.5)

پلتفرم مدرن، سریع، سبک و دوزبانه (فارسی و انگلیسی) برای اطلاع‌رسانی اخبار دانشگاهی، اطلاعیه‌های تعطیلی، تخفیف‌های ویژه دانشجویی (آفینو)، تعاملات (پسندیدن و دیدگاه‌ها)، تبلیغات بومی و پنل مدیریت.

---

## 🚀 ویژگی‌های کلیدی و معماری به‌روزرسانی‌شده

1. **آدرس‌های کاملاً تمیز (Clean URLs بدون علامت `#`):**
   - معماری مسیریابی به استاندارد **HTML5 History API** (`pushState` و `popstate`) ارتقا یافته است.
   - آدرس‌های مرورگر کاملاً تمیز و استاندارد هستند:
     - `http://localhost/player/uni/` (خانه)
     - `http://localhost/player/uni/afino` (آفینو)
     - `http://localhost/player/uni/settings` (تنظیمات)
     - `http://localhost/player/uni/admin` (پنل مدیریت)
   - حتی با رفرش مستقیم صفحه در هر یک از این مسیرها، سرور به درستی از طریق Rewrite به صفحه مربوطه پاسخ می‌دهد.

2. **پیکربندی پیشرفته آپاچی (`.htaccess`):**
   - پشتیبانی خودکار از **Extensionless API Routing**؛ یعنی درخواست‌ها هم به صورت `/api/news/list` و هم `/api/news/list.php` به صورت مستقیم و با بالاترین سرعت پردازش می‌شوند.
   - فعال‌سازی فشرده‌سازی **Gzip / Deflate** برای کاهش حجم تبادل داده‌های متنی، JSON، CSS و JS.
   - کش‌گذاری فایل‌های استاتیک و چندرسانه‌ای (`mod_expires`).
   - لایه‌های امنیتی سخت‌گیرانه برای جلوگیری از دسترسی مستقیم به پوشه‌های `config`, `core`, `models`, `services`, `install`, `logs` و فایل‌های حساس `.env`, `.sql`, `.log`.
   - هدرهای امنیتی `X-Content-Type-Options`, `X-Frame-Options`, `X-XSS-Protection`, `Referrer-Policy`.

3. **کدنویسی با آخرین نسخه PHP (PHP 8.5 / 8.4):**
   - اعمال `declare(strict_types=1);` در سرتاسر تمامی ۷۲ فایل PHP پروژه.
   - استفاده از **PHP 8.1+ Enums** در فایل `config/enums.php` برای مدیریت تایپ-سیف نقش‌ها (`UserRole`)، وضعیت‌ها (`UserStatus`, `NewsStatus`, `OfferStatus`, `AdStatus`) و اکشن‌های لاگ (`AdminAction`).
   - ویژگی‌های مدرن PHP 8.5: Constructor Property Promotion، تایپ‌های صریح ورودی و خروجی (`never`, `void`, `string|false`, `array|null`)، Nullsafe operator (`?->`)، Match expressions، و عدم استفاده از توابع و ثابت‌های Deprecated.

## 📂 ساختار فایل‌های پروژه

```
uni/
├── index.php                      ← نقطه ورود و لایه SPA
├── .htaccess                      ← پیکربندی وب‌سرور آپاچی، فشرده‌سازی و Clean URLs
├── config/
│   ├── config.php                 ← تنظیمات اتصال دیتابیس، پیامک و آپلود
│   ├── constants.php              ← ثابت‌ها و پل ارتباطی Enums
│   ├── enums.php                  ← انام‌های اختصاصی PHP 8.5 (UserRole, NewsStatus, ...)
│   └── database.php               ← اتصال PDO امن سازگار با PHP 8.5
├── core/
│   ├── Auth.php                   ← مدیریت نشست، کنترل سطح دسترسی و توکن CSRF
│   ├── RateLimit.php              ← کنترل نرخ درخواست‌ها با الگوریتم Token Bucket
│   ├── Request.php                ← تجزیه و اعتبارسنجی ورودی‌های HTTP و JSON
│   ├── Response.php               ← تولید پاسخ‌های استاندارد JSON با خروجی never
│   └── Validator.php              ← اعتبارسنجی شماره موبایل ایران، متون و URL
├── models/
│   ├── User.php                   ← مدل کاربران با پشتیبانی از تغییر دانشگاه و رشته
│   ├── News.php                   ← مدل اخبار و اطلاعیه‌های ساختاریافته تعطیلی
│   ├── Like.php                   ← مدل پسندیدن با ترنزکشن و جلوگیری از لایک تکراری
│   ├── Comment.php                ← مدل دیدگاه‌ها و سیاست تأیید/حذف
│   ├── Offer.php                  ← مدل تخفیف‌های آفینو و مدیریت انقضا
│   ├── Ad.php                     ← مدل تبلیغات بومی و سیستم آمار نمایش/کلیک
│   ├── University.php             ← مدل دانشگاه‌های پشتیبانی‌شده
│   ├── AdminLog.php               ← ثبت گزارش اقدامات مدیریتی (Audit Logs)
│   ├── Setting.php                ← تنظیمات سامانه و فاصله تبلیغات
│   └── OTP.php                    ← تولید و تأیید کدهای اعتبارسنجی
├── services/
│   └── SmsService.php             ← اتصال به کاوه‌نگار، ملی‌پیامک و شبیه‌ساز Mock
├── api/                           ← اندپوینت‌های JSON (پشتیبانی با یا بدون پسوند .php)
├── lang/
│   ├── fa.php                     ← زبان فارسی با ساختار RTL
│   └── en.php                     ← زبان انگلیسی با ساختار LTR
├── assets/
│   ├── css/                       ← استایل‌های مدرن با پوسته تاریک و روشن
│   └── js/                        ← فرانت‌اند جاوااسکریپت با SPA Clean URL Router
├── uploads/                       ← مسیر فایل‌های چندرسانه‌ای
├── install/
│   ├── schema.sql                 ← ساختار کامل پایگاه داده MySQL
│   └── setup.php                  ← نصب و ایجاد حساب مدیر ارشد اولیه
└── test_runner.php                ← اسکریپت آزمون‌های خودکار سیستم
```
